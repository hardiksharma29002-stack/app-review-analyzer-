# App Review Insights Analyzer — UI/UX Design Prompt

> **Context for AI UI Generators (v0, Bolt, Lovable, etc.):**
> I am building a "Weekly Product Pulse" dashboard for an app (like Groww). The backend is already built in Python (FastAPI). I need a stunning, high-definition, modern front-end for this web application.

## Design Aesthetic & Vibe
- **Framework & Style:** High-definition **Neumorphism** (Soft UI). Elements should look like they are extruded from or depressed into the background. Use extremely precise, soft inner and outer shadows to create a flawless 3D effect without harsh borders.
- **Day/Dark Mode Toggle:** The UI MUST include a smooth, animated toggle to switch between Day Mode and Dark Mode. 
- **Color Palette (Dark Mode):** 
  - **Background:** Soft, matte charcoal (`#1E1E24`)
  - **Neumorphic Shadows:** Highlights with `#2A2A33`, shadows with `#121216`
  - **Accents:** Emerald Green (`#00D09C`) for active states and charts.
- **Color Palette (Day Mode):**
  - **Background:** Ultra-soft off-white (`#E0E5EC`)
  - **Neumorphic Shadows:** Highlights with `#FFFFFF`, shadows with `#A3B1C6`
  - **Accents:** Vibrant Emerald Green (`#00D09C`)
- **Typography:** `Outfit` (Google Fonts). Geometric, highly legible, sans-serif. Use heavy font weights (700/800) for large headers and regular (400) for body text.

## Core Layout (Single Page Application)
The page should be a highly responsive, single scrollable dashboard that scales perfectly from 4K desktop monitors down to mobile phones. It has three main sections:

### 1. The Hero Section (Header)
- **Top Bar:** A sleek logo on the top left ("App Review Insights"). 
- **Centerpiece:** A large, bold headline: "Turn User Noise Into Product Strategy."
- **Action Area:** A prominent, glowing primary button: **"Generate Weekly Pulse"**. When clicked, this button should show a beautiful spinning loading animation (indicating that the AI is processing).

### 2. The Report View (Hidden until generation completes)
Once the "Generate" button finishes, this dashboard area fades in smoothly:
- **Top 3 Themes Cards:** A horizontal row of 3 glassmorphic cards. Each shows a theme (e.g., "App Performance & UX"), a large percentage number (e.g., "34%"), and a small trending icon.
- **Actionable Recommendations:** A sleek list layout highlighting 3 bullet points generated by the AI. Give this section a subtle glowing border to indicate it's AI-generated.
- **Voice of the Customer (Quotes):** A masonry or grid layout of 3 quote cards. Use italicized serif fonts for the quotes to make them look like real testimonials, with a 1-5 star rating component at the top of each card.

### 3. The Footer / Export Actions
- **Buttons:** A secondary row of buttons below the report:
  1. **"Download PDF"** (Ghost button with an outline)
  2. **"Email Report to Team"** (Solid button). Next to this, an elegant plain-text input field saying "Enter email address...".

## Micro-Interactions & Polish
- **Hover Effects:** Cards should slightly elevate (`transform: translateY(-4px)`) and increase their shadow glow on hover.
- **Loading State:** When the user clicks Generate, the screen should subtly dim, and a pulsing, high-tech loading spinner should appear in the center with text cycling through: "Scraping Reviews...", "Scrubbing PII...", "Classifying Themes...", "Generating Insights...".
- **Responsive:** Must look incredible on both a 4K desktop monitor and a mobile phone.

## Deliverables Required
Please generate the HTML, CSS, and minimal vanilla JavaScript to create this entire single-page experience. Ensure the design looks like a million-dollar startup product.
